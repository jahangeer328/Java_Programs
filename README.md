# Java Practice Lab

A collection of clean, well-commented Java programs written to master the core concepts of the language, ranging from syntax basics to advanced type safety with generics.

## 🚀 Topics Covered

* **Fundamentals:** Variables, data types, control flow, loops, and arrays.
* **Object-Oriented Programming (OOP):** Classes, objects, inheritance, polymorphism, encapsulation, and abstraction.
* **Exception Handling:** Try-catch blocks, custom exceptions, and resource management.
* **Collections Framework:** Working with Lists, Sets, Maps, and utility classes.
* **Generics:** Type-safe classes, interfaces, generic methods, and wildcards.
